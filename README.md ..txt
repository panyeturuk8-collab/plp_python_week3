
# PLP Python Week 3 Assignment

## Files

- grade_reporter.py: Calculates grades, pass count, fail count, and average score.
- bug_hunt.py: Fixes three bugs and calculates the sum of numbers 1 to 5.
- README.md: Describes the assignment files and debugging process.

## Bug Hunt Reflection

The hardest bug to find was the loop condition because the program ran without an error but produced the wrong answer. I knew something was wrong because the expected sum was 15, but the program did not include the number 5. Changing the condition to count <= 5 fixed the problem.
